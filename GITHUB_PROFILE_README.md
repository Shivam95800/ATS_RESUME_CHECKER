### 🚀 Featured Project: ATS Resume Intelligence

> **Live Application**: [ats-resume-checker-nine-lake.vercel.app](https://ats-resume-checker-nine-lake.vercel.app)  
> **Source Code**: [github.com/Shivam95800/ATS_RESUME_CHECKER](https://github.com/Shivam95800/ATS_RESUME_CHECKER)

- **Semantic Embedding Match**: Dense vectors (`all-MiniLM-L6-v2`) compute contextual resume-to-JD cosine alignment.
- **Project Evidence Verification**: Validates whether claimed skills are substantiated by actual bullet point projects.
- **Production Architecture**: Containerized FastAPI backend on Render + Next.js 16 App Router on Vercel + Supabase Auth & PostgreSQL with RLS.
- **Automated Gating**: 19 passing Pytest integration tests + Playwright Chromium E2E smoke tests.
